# 组合数与 $O(1)$ 逆元

> **用途：** 在固定质数模数下预处理阶乘、逆阶乘，并在常数时间内计算逆元与组合数。
>
> **复杂度：** 初始化约为 $O(n+mod^{2/3})$ 量级，空间复杂度 $O(n+mod^{2/3})$；单次 `inv`、`fac`、`ifac` 和组合数查询均为 $O(1)$。
>
> **使用条件：** $B\ge mod^{1/3}$；当前参数取 $mod=998244353$、$B=1024$。

**已验证数据范围：** $mod$ 为质数且 $N<mod$；按当前 `i64` 中间乘法实现，取 $mod\le3\times10^9$，小质数同样适用。

**常数参考：** 当前 `i64` 实现取 $mod=998244353$、$B=1024$、$N=10^6$ 时，耗时约 $24\,\mathrm{ms}$；若将模乘中间量改为 `i128`，取 $mod=3\times10^{10}$、$B=3136$、$N=10^6$ 时，耗时约 $0.8\,\mathrm{s}$。

| 操作/结构 | 含义 | 复杂度 | 已验证数据范围 |
| --- | --- | --- | --- |
| `qpow(a, n)` | 计算 $a^n\bmod mod$ | $O(\log n)$ | $0\le n\le 2^{63}-1$，$a$ 可为任意 `i64` |
| `inv(x)` | 返回 $x^{-1}\bmod mod$ | $O(1)$ | $1\le x<mod$ |
| `fac(n)` | 返回 $n!\bmod mod$ | $O(1)$ | $0\le n\le N$ |
| `ifac(n)` | 返回 $(n!)^{-1}\bmod mod$ | $O(1)$ | $0\le n\le N$ |
| `comb(n, k)` | 返回 $\binom nk\bmod mod$ | $O(1)$ | $0\le k\le n\le N$ |
| `Comb(n)` | 初始化阶乘、逆阶乘和逆元查表 | $O(n+mod^{2/3})$ | $1\le n\le N$ |

```cpp
const int mod = 998244353, N = 1e6;

int qpow(int a, int n) {
    a %= mod;
    int ans = 1;
    while (n) {
        if (n%2) ans = ans*a%mod;
        a = a*a%mod;
        n/=2;
    }
    return ans;
}

namespace Combination {
    struct Comb {
        const int B = 1024; // mod^(1/3)
        vector<int> fac, ifac;
        vector<int> INV, U;

        int inv(int x) {
            x %= mod;
            int u = U[x/B];
            int tmp = u*x%mod <= B*B*2 ? INV[u*x%mod] : mod-INV[-(u*x%mod-mod)];
            return u*tmp%mod;
        }

        Comb(int n = 0) {
            if (n == 0) return;
            INV.resize(B*B*2+1);
            INV[1] = 1;
            for (int i = 2; i <= B*B*2; i++) {
                INV[i] = (mod-mod/i*INV[mod%i]%mod)%mod;
            }
            U.resize(B*B+1, 1);
            if (mod-B*B > 0) {
                int R = mod-B*B;
                for (int u = 1; u <= B; u++) {
                    int tmp = u*B;
                    for (int a = 0; a <= B*B;) {
                        int cur = tmp*a%mod;
                        if (cur <= B*B) U[a] = u;
                        else if (cur >= R) U[a] = mod-u;
                        else {
                            int A = (R - cur) / tmp;
                            a += A;
                        }
                        a++;
                    }
                }
            }

            fac.resize(n+1);
            ifac.resize(n+1);
            fac[0] = 1;
            for (int i = 1; i <= n; i++) {
                fac[i] = (int)fac[i-1]*i%mod;
            }
            ifac[n] = inv(fac[n]);
            for (int i = n-1; i >= 0; i--) {
                ifac[i] = (int)ifac[i+1]*(i+1)%mod;
            }
        }
        int operator()(int n, int k) {
            if (k < 0 || k > n) return 0;
            return (int)fac[n]*ifac[k]%mod*ifac[n-k]%mod;
        }
    }comb(N);
    int fac(int n) {return comb.fac[n];}
    int ifac(int n) {return comb.ifac[n];}
    int inv(int n) {return comb.inv(n);}
}
using namespace Combination;
```
