# Min_25 筛

> **用途：** 求一类积性函数的前缀和，尤其适合函数在质数与质数幂处容易计算、但查询上界很大的场景。
>
> **复杂度：** 常见多项式型质数取值下，时间复杂度约为 $O(n^{3/4}/\log n)$，空间复杂度 $O(\sqrt n)$；实际复杂度取决于 $f(p^e)$ 的计算方式。
>
> **说明：** 本页保留的是框架片段，需要与外部的质数表、整除分块下标、`cal1`、`resG`、`sfp` 和具体积性函数定义配合。

构造完全积性函数 $F(p) = f(p)$，其中 $p$ 是质数。

定义

$$
G(j,n) = \sum\limits_{i=1}^n F(i)
[i\text{ 是质数，或者 }i\text{ 的最小质因子}>p_j].
$$

初始 $G(j,n) = \sum\limits_{i=2}^n F(i)$。

转移

$$
G(j,n) = G(j-1,n)
-F(p_j)\left(
G\left(j-1,\left\lfloor \frac{n}{p_j} \right\rfloor\right)
-\sum\limits_{i=1}^{j-1}F(p_j)
\right).
$$

实现如下：

```cpp
#define index(x) (x <= N ? idx1[x] : idx2[n/(x)])
vector<int> idx1(N+9),idx2(N+9),tmp;
int cnt = 0;
for (int l = 1, r; l <= n; l = r+1) {
    r = n/(n/l);
    int x = n/l;
    tmp.push_back(x);
    if (x <= N) idx1[x] = ++cnt;
    else idx2[n/x] = ++cnt;
}
sort(tmp.begin(),tmp.end(),greater());

vector<int> g(N+9);
for (auto j : tmp) g[index(j)] = (cal1(j)-1+mod)%mod; //初始化
int sum = 0;
for (int i = 1; prime[i]*prime[i] <= n; i++) {
    for (auto j : tmp) {
        if (prime[i]*prime[i] > j) break;
        int idx = index(j);
        int idx0 = index(j/prime[i]);
        (g[idx] += mod - prime[i]%mod*(g[idx0]-sum+mod)%mod) %= mod;
    }
    (sum += prime[i]) %= mod;
}
```

定义

$$
S(n,j)=\sum\limits_{i=1}^{n}f(i)
[i\text{ 的最小质因子}>p_j].
$$

转移

$$
S(n,j) =
g(|P|,n)-\sum\limits_{i=1}^{j-1}f(p_i)
+\sum\limits_{k=j+1}^{p_k^2\le n}
\sum\limits_{e=1}^{p_k^e\le n}
f(p_k^e)
\left(
S\left(\left\lfloor\frac{n}{p_k^e}\right\rfloor,k\right)
+[e>1]
\right).
$$

```cpp
int S(int n, int j) {
    if (j && prime[j] >= n) return 0;
    int idx = n <= N ? idx1[n] : idx2[N*N/n];
    int res = (resG[idx] - sfp[j] + mod)%mod;
    for (int i = j+1; prime[i]*prime[i] <= n; i++) {
        int p = prime[i];
        for (int e = 1; p <= n; e++) {
            res += p%mod*((p-1)%mod)%mod * (S(n/p,i) + (e != 1))%mod;
            res %= mod;
            p *= prime[i];
        }
    }
    return res;
}
```
