# 直线

> **用途：** 用两个端点表示有向直线，计算方向角或两条直线的交点。
>
> **复杂度：** 单次 `angle` 或 `crs` 均为 $O(1)$。
>
> **使用条件：** `crs(a, b)` 只用于 `Line<double>`，并要求两条直线不平行，即 $(a.e-a.s)*(b.e-b.s)\ne 0$；模板不检查此前置条件。

```cpp
template <typename T>
struct Line {
    Point<T> s, e;
    Line(Point<T> s_ = {0, 0}, Point<T> e_ = {0, 0}) {
        s = s_, e = e_;
    }

    double angle() const {
        return atan2l((e-s).y, (e-s).x);
    }
};

Point<double> crs(const Line<double> &a, const Line<double> &b) {
    double x = (a.e-b.e)*(b.e-b.s);
    double y = (a.e-a.s)*(b.e-b.s);
    return a.e-(a.e-a.s)*(x/y);
}
```
