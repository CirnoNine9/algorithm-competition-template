# 任意多边形

> **用途：** 计算任意简单多边形的有向二倍面积、面积，并判断点在多边形外部、边界或内部。
>
> **使用条件：** 顶点数至少为 $3$，按边界顺序给出且不重复首点，多边形不能自交。`pointPolygonRelation()` 按精确比较书写，浮点判定需自行改用 `eps`。整数坐标为 `i64` 时，叉积及其总和必须在 `i64` 范围内，否则相应运算改为 `i128`。

| 接口 | 含义 | 复杂度 | 备注 |
|---|---|---|---|
| `polygonArea2(a)` | 有向二倍面积，逆时针为正、顺时针为负 | 时间 $O(n)$，空间 $O(1)$ | 至少 $3$ 点，按边界顺序且不重复首点，多边形不自交；`i64` 叉积及总和不得溢出 |
| `polygonArea(a)` | 多边形面积 | 时间 $O(n)$，空间 $O(1)$ | 条件同 `polygonArea2(a)` |
| `pointPolygonRelation(p, a)` | 点在外部、边界、内部分别返回 $0,1,2$ | 时间 $O(n)$，空间 $O(1)$ | 至少 $3$ 点，按边界顺序且不重复首点，多边形不自交；浮点判定需改用 `eps`，`i64` 叉积不得溢出 |

```cpp
template <class T>
T polygonArea2(const vector<Point<T>> &a) {
    int n = a.size();
    T ans = 0;
    for (int i = 0; i < n; i++) {
        ans += a[i]*a[(i+1)%n];
    }
    return ans;
}

template <class T>
double polygonArea(const vector<Point<T>> &a) {
    T ans = polygonArea2(a);
    if (ans < 0) ans = -ans;
    return ans/2.0;
}

template <class T>
int pointPolygonRelation(const Point<T> &p, const vector<Point<T>> &a) {
    int n = a.size(), in = 0;
    for (int i = 0; i < n; i++) {
        int j = (i+1)%n;
        if (onSegment(p, Line<T>(a[i], a[j]))) return 1;
        T cross = (a[j]-a[i])*(p-a[i]);
        if (a[i].y <= p.y && p.y < a[j].y && cross > 0) in ^= 1;
        if (a[j].y <= p.y && p.y < a[i].y && cross < 0) in ^= 1;
    }
    return in ? 2 : 0;
}
```
