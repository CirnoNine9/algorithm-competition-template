# 算法竞赛模板总目录

## 使用说明

- 每个板子独立成页，标题下方统一给出用途、复杂度和主要使用条件。
- 分类目录按推荐打印顺序排列；直接按文件名排序即可得到整套顺序。
- 代码正文从原始 `板子.md` 拆出，没有根据审查结论改动实现。
- 已发现的风险点与最小反例集中记录在[代码审查与反例](../代码审查.md)，避免在赛前抄板时忽略。

## 分类

1. [数论](01-数论/README.md)：组合数、同余、离散对数、筛法、质数计数、因数分解与类欧几里得。
2. [计算几何](02-计算几何/README.md)：点与凸包、直线、半平面交。
3. [数据结构](03-数据结构/README.md)：树状数组、线段树、Treap、`pb_ds`、Link–Cut Tree。
4. [图论与网络流](04-图论与网络流/README.md)：Dinic、HLPP。
5. [多项式](05-多项式/README.md)：插值、各类变换、形式幂级数与 Power Projection。
6. [Python](06-Python/README.md)：`datetime`、`Fraction`、`math` 常用接口。
