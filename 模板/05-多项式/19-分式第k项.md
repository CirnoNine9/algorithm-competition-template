# 分式第 $k$ 项

> **用途：** 用多项式带余除法与 Bostan–Mori 算法计算
> $[x^k]\frac{f(x)}{g(x)}$，
> 对 $f,g$ 的次数关系没有要求，也无需展开前 $k$ 项。
>
> **复杂度：** 若多项式长度为 $n$，使用快速卷积时为 $O(n\log n\log k)$，空间 $O(n)$。
>
> **使用条件：** $k\ge0$，`g[0]` 与最高次项必须可逆，`f,g` 末尾没有无意义的零系数；依赖外部多项式乘法、整除与取模。

```cpp
int divAt(vector<int> f, vector<int> g, int k) {
    vector<int> p;
    if (f.size() >= g.size()) p = f/g, f = f%g;
    int res = 0;
    if (k < (int)p.size()) res = p[k];
    if (f.empty()) return res;
    for (int i; k; k /= 2) {
        auto h = g;
        for (i = 1; i < (int)h.size(); i+=2) h[i] = (mod-h[i])%mod;
        f *= h, g *= h;
        for (i = 0; i*2+k%2 < (int)f.size(); i++) f[i] = f[i*2+k%2];
        f.resize(i);
        for (i = 0; i*2 < (int)g.size(); i++) g[i] = g[i*2];
        g.resize(i);
    }
    (res += f.size() ? f[0]*inv(g[0]) : 0) %= mod;
    return res;
}
```
