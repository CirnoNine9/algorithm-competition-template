# 多项式乘法逆

> **用途：** 求形式幂级数 $g(x)$，使 $f(x)g(x)\equiv1\pmod{x^n}$。
>
> **复杂度：** 使用 NTT 卷积时为 $O(n\log n)$，临时向量占用 $O(n)$ 空间。
>
> **使用条件：** 必须有 $f(0)\ne0$；主版本对 `998244353` 取模，任意模数时改用下方 MTT 版本。

可以先记录并除去前导的 $x^k$，使常数项非零，再处理带平移的逆。

**常数参考（ms）：**

| NTT | $n=10^5$ | $n=2\times10^5$ | $n=5\times10^5$ | $n=10^6$ |
| --- | ---: | ---: | ---: | ---: |
| 普通 NTT | 19.570 | 41.949 | 97.180 | 215.286 |
| 卡常 NTT | 17.051 | 36.511 | 76.005 | 159.417 |

```cpp
vector<int> inv(vector<int> f) {
    int n = f.size();
    vector<int> g(n);
    g[0] = inv(f[0]);

    for (int m = 1; m < n; m <<= 1) {
        int k = 2*m;
        vector<int> a(k), b(k);
        copy(f.begin(), f.begin()+min(n, k), a.begin());
        copy(g.begin(), g.begin()+m, b.begin());

        ntt(a, k, 1), ntt(b, k, 1);
        for (int i = 0; i < k; i++) a[i] = a[i]*b[i]%mod;
        ntt(a, k, -1);

        fill(a.begin(), a.begin()+m, 0);
        ntt(a, k, 1);
        for (int i = 0; i < k; i++) a[i] = a[i]*b[i]%mod;
        ntt(a, k, -1);

        for (int i = m; i < min(n, k); i++) g[i] = a[i] ? mod-a[i] : 0;
    }
    return g;
}
```

使用 MTT 时改用下面只依赖 `operator*=` 的版本；此时 `inv(f[0])` 也应能在当前 $mod$ 下正确求逆。

```cpp
vector<int> inv(vector<int> f) {
    if (f.size() == 1) return {inv(f[0])};
    int n = f.size(), m = (n+1)/2;
    auto h = f;
    h.resize(m), h = inv(h);

    f *= h;
    f.resize(n);
    for (auto &x : f) x = x ? mod-x : 0;
    f[0] += 2;
    if (f[0] >= mod) f[0] -= mod;
    f *= h;
    f.resize(n);
    return f;
}
```
