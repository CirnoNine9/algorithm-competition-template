# 算法竞赛模板

这套模板采用“一个算法一份正文、分类页负责汇总”的结构。

- [完整 A4 打印版 PDF（GitHub Releases）](https://github.com/CirnoNine9/algorithm-competition-template/releases/latest)
- [拆分版总目录](模板/README.md)
- [通用竞赛骨架](org.cpp)

维护时只修改 `模板` 目录中的对应小文件。文件名前的编号同时也是推荐打印顺序。

打印版由 [build_print_pdf.ts](build_print_pdf.ts) 按编号汇总生成，版式定义在 [打印版.css](打印版.css)。
